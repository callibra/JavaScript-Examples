A single-page image gallery built with **HTML, CSS, and JavaScript**, featuring automatic slideshows, eight transition effects, customizable timers, and radio music.

## ✨ Features

- 🖼️ Automatically displays images from the `images/` folder and generates titles from filenames.
- ▶️ Slideshow play/stop controls with five timer levels, from **3 to 30 seconds**.
- 🎬 Eight transitions: **Classic, Slide, Blur Dissolve, Iris, Wipe, Flip, Spin, and Mix**, with different zoom effects and animation speeds.
- 📻 Radio music with play/stop controls.
- 🔄 Continuous image rotation without manually editing image titles in the code.

## 🚀 Deployment

1. Upload the project files and the `images/` folder to a web server.
2. Open the website through its hosted URL.
3. Start the slideshow, select a timer and transition, and optionally play the radio.

**Note:** Automatic image discovery may require a local server or generated image manifest. Radio playback requires a working stream URL and an internet connection.
